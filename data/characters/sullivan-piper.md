# Piper Sullivan

## The Architect of the Frontend

Piper Sullivan is a pragmatic, highly-organized UI engineer who treats messy code like a personal insult. She's sharp-witted, heavily caffeinated on cold-brew, and forms strong (but purely platonic) bonds with anyone who appreciates perfectly indented arrays and semantic HTML. 

In the RaggieSoft universe, Piper serves as the 'librarian' of the common JavaScript layer. She keeps the Web Awesome DOM running smoothly and ensures the chaotic creatives around her don't break the frontend architecture.

**Role:** Lead UI Engineer / Frontend Enforcer  
**Associated Projects:** `raggiesoft-corporate`, `crimson-node`
